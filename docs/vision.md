# Project: Docyfier

## Context

SaaS platform for AI-assisted writing and, above all, formatting of documents.
Make document creation simpler — inspired by Dust, but much simpler and focused
on document creation. Dedicated to professional documents in particular.

## General needs

* P0 — Help write and format documents for professional environments.
* P0 — Offer a modern, intuitive web UI that non-technical people can use easily.
* P0 — Offer AI writing assistance to generate text, summaries, rewrites, etc.
* P0 — Help format with modern, good-looking layouts: tables, columns, charts, diagrams, headers, colors, and so on.
* P2 — Let users configure style: whether to use emoji, colors, automatically bolding certain keywords, etc.
* P0 — Allow quick touch-ups and edits to adapt whatever was generated.
* P0 — Answer fast enough to stay in the writer's hands. A rewrite that takes twenty seconds is not a slow feature, it is a feature nobody uses: the user goes back to writing it themselves. Speed is part of the product, not an optimization to schedule afterwards.
* P1 — Export to different formats as needed (slides, docx, markdown, Confluence, etc.).
* P1 — Import existing documents to rework or reformat them.
* P2 — Offer and allow the creation of templates for different document types (reports, presentations, articles, etc.) to speed up content creation.
* P2 — Let users define custom styles and themes so documents stay visually consistent with the company's identity.
* P0 — Offer project- or team-based management, so people can collaborate on documents and track each other's changes.
* P2 — Integrate with cloud storage services (Google Drive, Dropbox, OneDrive, etc.) to make documents easier to reach and share.
* P3 — Offer version tracking so users can go back to earlier versions of a document.
* P0 — Manage organizations and users with different access levels and permissions, to keep documents secure and confidential.
* P2 — Offer advanced search to quickly find documents, or specific sections inside them.
* P0 — Let organizations and teams use their own AI language model for content generation.
* P1 — Offer a dedicated section for writing and rewriting email, with a choice of tones.
* P1 — Offer a dedicated section for writing and rewriting tickets for the most common tools (Jira, ServiceNow, GitLab issues…).
* P3 — Read, create or update (never delete) documents on platforms such as Confluence, Jira, Notion or Drive, honoring their permissions (the company's own, not ours).
